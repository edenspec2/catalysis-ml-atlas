MILO LAB

Ten minutes, then a habit.

This is a curated map of homogeneous catalysis × ML — not the whole field, and not a PDF library. Zotero keeps the files. The atlas keeps what the paper is for: n, validation, and stack layer.

Three shelves

  1. Shared atlas — the curated core (summaries, stack). Only a curator promotes a paper here.
  2. My shelf — Save, Read, and a private note on this browser. Export my shelf to move laptops. This is not yet synced across the group.
  3. Lab queue — Propose a DOI as a GitHub issue. Someone reviews it, then it can enter the atlas.

First ten minutes

  1. Switch to Inspect (or tap Inspect). Scan n, validation, and stack layer. Cards are for browsing; this table is for deciding.
  2. Open 3D atlas. Drag to rotate, Shift-drag to pan. Stories on the top row are the scientific cuts (Milo neighborhood, descriptor tools, computational stack).
  3. Pick one paper you actually need this week. Details → Save, Mark as read, and write a one-line note.

Add a paper the lab can see

  1. Discover latest → paste a DOI → Search Crossref.
  2. Add to my library if you want it on this device today.
  3. Details → Propose for the shared atlas. Fill the one-sentence why, chemistry, stack, n, and validation. Do not paste the abstract.
  4. Put the PDF in the group Zotero collection. Do not attach publisher PDFs to GitHub.

Export into the tools you already use

Filter the library (or Inspect), then Export BibTeX for that view. Use Export my shelf / Import shelf when you switch browsers. Similarity links in the 3D graph are not citations.

What this is not

  • Not an exhaustive literature search.
  • Not a replacement for Zotero, Eln, or group Slack.
  • Not a dump of every catalysis-ML paper. If a DOI does not belong in this core, it can stay on your shelf.
